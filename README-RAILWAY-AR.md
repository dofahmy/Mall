# ميجا مول وفر كاش — V1.1 (Railway)

## تشغيلها على Railway

1. فك ضغط الملف، وارفع **محتويات المجلد** إلى Repository جديد على GitHub (بحيث `app.py` و`railway.json` موجودين في جذر المستودع).
2. من Railway: New Project → Deploy from GitHub Repo → اختار المستودع الجديد. **لا تستخدم خدمة وفر كاش القديمة.**
3. من Variables أضف `DEMO_MODE=1` للتجربة في أي متصفح، و`DATABASE_PATH=/data/megamal.db`.
4. من خدمة Railway اختار إضافة Volume وحدد Mount Path = `/data` لحفظ قاعدة SQLite بين مرات النشر. لا ترفق ملف قاعدة بيانات قديم.
5. من Settings → Networking → Generate Domain، افتح الرابط. فحص الخدمة: `/health`.
6. اللعبة في وضع DEMO تعرض 3 لاعبين تجريبيين لاختبار البيع والشراء. لا تشارك الرابط مع الجمهور وهي في هذا الوضع؛ **كل زائر يستطيع التحكم في الحسابات التجريبية نفسها.**

## تشغيلها داخل Telegram

1. أنشئ بوت تجريبي **جديد** عبر BotFather (لا تستخدم توكن بوت وفر كاش الحالي).
2. اضبط Railway Variables: `BOT_TOKEN=<token>` و`DEMO_MODE=0`.
3. اضبط Mini App URL كزر Menu Web App في BotFather للبوت الجديد، باستخدام رابط Railway `https://...up.railway.app`.
4. افتح اللعبة من زر Menu داخل البوت حتى يتم تمرير Telegram `initData` والتحقق منه على السيرفر. فتح الدومين مباشرةً بالمتصفح في هذا الوضع لن يسمح بالدخول.

## مهم

- فقط عملات افتراضية: لا يوجد سحب، شراء بأموال حقيقية، أو Telegram Stars في هذه النسخة.
- **قاعدة SQLite مخصصة لتجربة محدودة في خدمة واحدة**؛ عند التوسع لآلاف المستخدمين ننقل إلى PostgreSQL ونضيف ضوابط تشغيل وإساءة استخدام.
- الديكورات وعناصر المول مرسومة مبدئيًا عبر emoji وCSS؛ ليست نفس رسومات الموكاب ثلاثية الأبعاد.
- التطبيق يعرض صافي عمولة السوق بالعملات الافتراضية فقط.
- لا تنشر الأسرار أو التوكنات في GitHub. أضفها داخل Railway Variables فقط.
