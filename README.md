# ميجا مول وفر كاش — V1 — تجربة مرئية

نسخة V1 بواجهة وردية/باستيل ولوحة مول تفاعلية ومهام إرشادية، قابلة للتشغيل على Flask: دمج قطع، طاقة، خبرة، مستويات، 5 محلات، تصنيع أصول رقمية، سوق تداول بين مستخدمين، عمولة افتراضية 10%، وسجل معاملات. **لا توجد أموال حقيقية ولا بطاقات هدايا ولا شراء Stars ولا سحب نقدي.**

## التشغيل المحلي

```bash
pip install -r requirements.txt
python app.py
```

افتح `http://localhost:5000`. يوجد 3 حسابات تجريبية من شاشة السوق. اصنعي عنصرًا على الحساب الأول واعرضيه، ثم اختاري حسابًا آخر لشرائه. هذه الحسابات متاحة **فقط** حين `DEMO_MODE=1`، وغير آمنة للنشر العام.

## التشغيل على Railway

1. ارفعي ملفات هذا المجلد إلى GitHub كمشروع مستقل (لا تخلطيه مع كود وفر كاش القديم قبل اختبارات الدمج).
2. افتحي خدمة Railway جديدة، ووجهي Root Directory إلى مجلد المشروع عند الحاجة.
3. أمر التشغيل: `python start.py` (الخادم يقرأ `PORT` من بيئة Railway).
4. أضيفي Volume دائم مربوطًا على `/data`، و `DATABASE_PATH=/data/megamal.db`، و `DEMO_MODE=0` و `BOT_TOKEN` للبوت الصحيح. **لا تضعي التوكن في GitHub.**
5. اربطي رابط HTTPS للـMini App مع البوت عبر @BotFather / Mini App أو زر web_app، واختبري التحقق من initData.
6. افتحي `/health` للتأكد من عمل السيرفر. لا تعتمدي SQLite عند تزايد عدد عمليات التداول أو قبل إضافة اختبارات وتحكّمات إنتاجية؛ انقلي إلى PostgreSQL.

## الأمان وحدود النسخة

- يتم التحقق من Telegram `initData` بخوارزمية HMAC-SHA256 على السيرفر وبصلاحية يوم واحد، مع منع الاعتماد على `initDataUnsafe`.
- كل تعديلات الرصيد والتداول تتم داخل SQLite transaction بـ`BEGIN IMMEDIATE`، وبفحص ملكية الأصل والرصيد من جهة السيرفر.
- يمنع شراء اللاعب لأصله وبيع الأصل أكثر من مرة. عمولة 10% **بعملات افتراضية**.
- **ليست جاهزة بعد لاستقبال مدفوعات أو سحب حقيقي**: تحتاج إلى PostgreSQL، تدقيق حسابات، قيود إنتاج وanti-bot، مراقبة احتيال، سياسة خصوصية وشروط خدمة، الامتثال لقواعد Telegram Stars، مراجعة قانونية وشرعية، واختيار مقدم دفع مرخص للسحب إذا كان النموذج مسموحًا.
- تسارع المستوى: 80 XP لكل مستوى. دمج مستوى 1 يمنح 10 XP و12 عملة، ثم تتزايد المكافآت. التصنيع من قطعة مستوى 4 يكلف 100 عملة ومن مستوى 5 يكلف 250.
- الطاقة في الديمو تبدأ 18؛ الاسترداد +5 كل دقيقة حتى 25 لتسهيل اختبار التجربة. قبل الإطلاق عدلي هذا الإيقاع.
- لا توجد في النسخة الأولى إعلانات أمازون، لمنع خلط الروابط الأفلييت مع المكافآت لحين مراجعة شروطهم.

## اختبار السوق

- لا يمكن السحب الحقيقي. السعر من 20 إلى 10,000 عملة. على عملية بقيمة 100 عملة: البائع يحصل على 90، وتسجل 10 كعمولة افتراضية.
- اختبري حساب 1 يصنع أصلًا ويعرضه؛ ثم حساب 2 يشتريه. لوحة السوق تجلب أحدث 100 عرض.

## الربط بالسيستم القديم

لا توجد ملفات سيستم «وفر كاش» القديم في المحادثة الحالية؛ الكود هنا مستقل. لدمجه دون خسارة بيانات، نحتاج نسخة من الكود الحالي ومخطط قاعدة البيانات، ونطابق مستخدمي Telegram IDs ونكتب migration منفصلًا. لا تستخدمي قاعدة بيانات الإنتاج لاختبار هذه النسخة.


## جديد V1

- واجهة عربية ملوّنة للموبايل قريبة من التصور البصري، مع مول مرئي يكبر بفتح الأقسام وشريط خبرة.
- لوحة Merge تفاعلية بالضغط على قطعتين متطابقتين، وتصنيع أصل مستوى 4 أو 5.
- شاشة مهام إرشادية (النسخة الحالية **لا** تحتسب مكافأة مستقلة للمهام).
- سوق افتراضي بين 3 لاعبين ديمو مع نقل الملكية وتسجيل عمولة 10%.
- **تنبيه:** التصميم 2D باستخدام CSS وEmoji وليس مشهدًا ثلاثي الأبعاد، ولا يوجد Drag & Drop حتى الآن؛ الدمج بالضغط.
- هذا مشروع مستقل ولا يحتوي بيانات عملاء وفر كاش الأصلية.

## تجربة سريعة

1. ثبتي Python ثم `pip install -r requirements.txt`.
2. شغّلي `python app.py` وافتحي `http://localhost:5000`.
3. افتحي «اللعبة»، اختاري قطعتين من نفس النوع والدرجة، واضغطي على كل واحدة للدمج.
4. اضغطي «إنتاج قطعة» لاستهلاك طاقة، و«+5 طاقة مجانية» كل دقيقة في الديمو.
5. ادمجي لحد المستوى 4، اختاري القطعة، ثم «صناعة أصل».
6. من «مخزني» اعرضي الأصل للبيع، وانتقلي إلى «السوق» وغيّري اللاعب واشتريه للتأكد من انتقال الملكية.
